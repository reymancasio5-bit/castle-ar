# Castle AR Implementation Plan

> **For agentic workers:** Use the written interfaces and focused parallel tasks, then independent final review.

**Goal:** GitHub Pages responsive web app with Google Sheets shared records and flexible Excel amount imports.
**Architecture:** Static React/Vite frontend; Apps Script Code.gs API over the existing workbook.
**Tech Stack:** TypeScript, React, Vite, SheetJS CE, Google Apps Script.
**Spec:** ../specs/2026-10-28-castle-ar-design.md

## Global constraints
- No login; shared edits use the exact source spreadsheet.
- GitHub Pages uses relative asset paths and no server routes.
- Never overwrite AR formulas or unrecognized sheet content.
- Integer cents; blank and zero are different.
- Source snapshot is explicitly marked preview until connected.

## Review focus
- Simultaneous writes and direct Sheet edits reject stale revisions.
- POST transport errors do not show false save success.
- Imported duplicate or malformed amounts cannot corrupt data.
- Preserve field/date/formula semantics of source.
- Mobile dialogs remain usable and keyboard accessible.
