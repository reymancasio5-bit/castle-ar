# Listings Implementation Plan

**Goal:** Add amount-free listings with owner and manager assignment across existing months.

**Architecture:** Dedicated listing catalog with owner mappings kept in the existing owner table. A single saveListing operation validates and expands into atomic monthly assignment, owner mapping, and catalog writes.

**Tech Stack:** React, TypeScript, Vite, Google Apps Script.

**Spec:** ../specs/2026-11-26-listings-design.md
