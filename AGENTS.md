# UI Copy Convention

Use Initial Capitals For Every Word in important UI text: headings, section titles, field labels, buttons, table headings, and short status labels. Keep "on" lowercase unless it begins the text (for example: Add Property Owner, Owner Name, Name on Bank Statement, Active Owner, Assigned Properties).

Keep explanatory sentences and help text in sentence case. Preserve user-entered names, property names, bank statement text, and other source data exactly; do not apply global CSS text-transform to user data. Apply this convention to future UI additions and edits.
